\section{Monte Carlo Simulation}
\label{sec:EXPERIMENT_MONTE_CARLO_SIMULATION}
\pcstart{s34}{2}

\Gls{mc} simulations are essential for:
\begin{itemize}
  \item Signal and background modeling
  \item Detector response simulation
  \item Efficiency calculations
  \item Systematic uncertainty estimation
\end{itemize}

\subsection{Event Generators}
\label{sec:EXPERIMENT_MONTE_CARLO_SIMULATION_EVENT_GENERATORS}

Common event generators used:
\begin{itemize}
  \item PYTHIA - general-purpose generator
  \item HERWIG - alternative hadronization model
  \item MadGraph - matrix element calculations
\end{itemize}

\subsection{Detector Simulation}
\label{sec:EXPERIMENT_MONTE_CARLO_SIMULATION_DETECTOR_SIMULATION}

Detector response is simulated using \gls{geant4}, which models particle interactions with detector materials.

\pcend{s34}
